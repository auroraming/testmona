# 用例脑图性能基准

版本：1.0  
日期：2026-10-29

## 目标与阈值

| 场景 | 数据构成 | 通过阈值 |
| --- | --- | --- |
| 常规画布 | 500 条用例，至少 25 个模块，每条含 4 个普通字段节点 | 进入脑图后首次可操作时间不超过 3 秒；连续平移、缩放和选中节点期间无超过 200ms 的长任务 |
| 结构化步骤 | 100 条多步骤用例，每条 5 个步骤及 5 个预期节点 | 选择用例至步骤节点可编辑不超过 1.5 秒（本地接口响应不超过 500ms 时） |
| 大项目 | 5,000 条用例，至少 100 个模块 | 首次只挂载最多 500 条用例；每次继续加载 500 条，按钮响应不超过 100ms，新增批次可操作不超过 2 秒 |
| 窄屏 | 390×844 CSS 像素 | 画布可平移缩放；详情以抽屉打开和关闭；关键按钮无需横向滚动即可访问 |

首次可操作时间从点击“脑图”视图开始，到画布完成初始化且“适应画布”按钮可响应为止。每个场景冷启动执行 3 次，记录中位数；交互测试至少持续 30 秒。

## 数据与测量规则

1. 使用专用测试项目，不使用生产数据；生成数据必须包含普通字段、多步骤、空字段、三级目录和未分目录用例。
2. 记录操作系统、CPU/内存、浏览器完整版本、前后端构建提交、是否启用开发者工具及网络条件。
3. 使用浏览器 Performance 面板记录首次可操作时间、主线程长任务和内存峰值；接口耗时使用 Network 面板记录。
4. 5,000 条用例场景验证目录总计数仍为服务端全量计数，搜索或筛选后重新从首批 500 条开始，且不会把列表当前分页误当作完整范围。
5. 若任一阈值失败，保存 trace、截图和数据生成参数；修复后使用相同数据重测，不以单次最好结果替代中位数。
